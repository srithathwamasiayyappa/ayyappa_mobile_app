# Ayyappa Aradhana – Screenshot Visual Specification

## Screen 1: Language Selection ("Chose your language")
1. **Header Bar**:
   - Background Color: Vivid Saffron/Deep Orange (`#E65100` / `#D84315`)
   - Text: "Chose your language" in bold white sans-serif.
   - Status bar: Dark themed, transparent or matches header.
2. **Background**:
   - Sacred golden-yellow textured geometry with radiant intersecting diagonal and cross bands (`#FDB813` / `#FFC107` / `#FFE082`).
3. **List Items**:
   - **Telugu**
   - **Kannada**
   - **English**
   - Text style: Bold, black (`#1A1A1A`), approx 18-20px, left-aligned with padding.
   - Right icon: Dark circular checkmark / radio button (`#262626` with checkmark icon).
   - Separator lines: Thin dark horizontal dividers (`#B26A00` / `rgba(0,0,0,0.2)`).

## Screen 2: Home Screen ("అయ్యప్ప ఆరాధన")
1. **Header Bar**:
   - Background Color: Deep Devotional Orange (`#D84315`)
   - Left Title: "అయ్యప్ప ఆరాధన" (White, bold, approx 20-22px)
   - Right Action Icons:
     - Info circle icon (`i`)
     - Share icon
     - Language translate icon (`A / 文`)
2. **Sub-Header / Moving Devotional Ribbon**:
   - Golden Yellow Bar (`#FFB300`)
   - Text: "శ్రీ స్వామియే శరణం అయ్యప్ప ॐ శ్రీ స్వామియే శరణం అయ్యప్ప..." with Om / floral sacred glyphs in purple & gold.
3. **Daily Calendar & Panchangam Card**:
   - Two-column card container:
     - Left (Date section): Orange container with large date **07** in yellow/gold, and **Nov** in dark bold text.
     - Right (Panchangam section): Orange-amber container with sacred details in yellow/cream:
       - "శ్రీ పరాభవ సంవత్సరం" (Sri Parabhava Samvatsaram)
       - "ఆశ్వయుజ - కృష్ణ పక్షం" (Aswayuja - Krishna Paksham)
       - "త్రయోదశి 10:48 am" (Trayodasi 10:48 am)
       - "చిత్త 5:52 am" (Chitta 5:52 am)
       - "శనివారము" (Sanivaramu)
4. **Devotional Audio & Category List Items**:
   Each list item has a golden-yellow textured background with thin brown divider lines:
   - **Item 1**: "2026 ఉత్తర నక్షత్ర తేదీలు" with circular Lord Ayyappa medallion on the left.
   - **Item 2 (Audio Player Item)**:
     - Title: "సుప్రభాతం" (Suprabhatham)
     - Ayyappa circular medallion on left.
     - Audio player bar: Download / Play circle button, progress slider bar with circular thumb, time stamps (`00:00` / `--:--`).
   - **Item 3**: "నిత్యపారాయణ శ్లోకములు" (Nitya Parayana Slokamulu) + Ayyappa medallion.
   - **Item 4**: "పూజలు వ్రతాలు" (Pujalu Vratalu) + Ayyappa medallion.
   - **Item 5**: "మాలాధారణ మంత్రం" (Mala Dharana Mantram) + Ayyappa medallion.
   - **Item 6**: "అయ్యప్ప శరణు ఘోష" (Ayyappa Sharanu Ghosha) + Ayyappa medallion.
   - **Item 7**: "నిత్య పూజ (లఘు విధానం)" (Nitya Pooja Laghu Vidhanam) + Ayyappa medallion.
   - **Item 8**: "స్తోత్రములు" (Stotramulu) + Ayyappa medallion.
   - **Item 9**: "పూజ పూర్వాంగము" (Pooja Poorvangamu) + Ayyappa medallion.
