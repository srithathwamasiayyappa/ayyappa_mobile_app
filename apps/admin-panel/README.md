# ayyappa_admin

Saranam Ayyappa Administrative Dashboard & Temple Management Portal built with Next.js, React, and Tailwind CSS.

## Overview
A comprehensive web portal for managing the Saranam Ayyappa ecosystem. Enables administrators and Dharma Karthas to manage sacred temples, devotional content, daily panchangam calendars, audio/video assets, donations, and mobile app configuration.

## Key Modules
- **Temple Management**: Full lifecycle management of temple profiles, historical origins, seva schedules, and location coordinates.
- **Dharma Kartha Verification**: Review and approve temple trustee applications and administrative privileges.
- **Daily Panchangam & Festivals**: Configure Vedic calendars, auspicious Tithis, Nakshatras, and annual temple festivals.
- **Devotional Content**: Curate pooja procedures, slokas, audio bhajans, and multi-language translations (Telugu, Tamil, Kannada, Malayalam, Hindi, English).
- **Annadanam & Donations**: Track spiritual offerings, prasadam distribution drives, and devotee contributions.
- **Dynamic CMS & System Settings**: Update About Us, Privacy Policy, Terms & Conditions, and mobile application branding in real time.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Devotional Theme styling
- **Icons**: Lucide React
