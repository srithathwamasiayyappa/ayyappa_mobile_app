# ayyappa_mobile_app

Saranam Ayyappa Devotional Mobile Application built with React Native and Expo.

## Overview
A comprehensive devotional mobile application for Lord Ayyappa devotees worldwide, featuring authentic Pooja Vidhanam, accurate daily Panchangam, temple discovery, live darshan streams, and multilingual support.

## Key Features
- **Daily Panchangam**: Real-time astrological calculations including Tithi, Nakshatra, Rahu Kalam, Yamagandam, Gulika Kalam, and sacred timings.
- **Temples in India**: Complete temple profiles, gopuram architecture, seva timings, and directions across India.
- **Pooja Vidhanam**: Step-by-step procedures, sacred hymns, slokas, and stotras with audio synchronization.
- **Annadanam & Sevas**: Community donation drives, temple events, and sacred offerings.
- **Devotee Profile**: Personalized Vedic profile, bookmarks, notifications, and language preferences.
- **Strictly Dynamic Data**: Live API synchronization with zero static or mock data fallbacks.

## Tech Stack
- **Framework**: React Native with Expo (SDK 52)
- **Language**: TypeScript
- **Styling**: React Native StyleSheet with custom devotional gold & forest green themes
- **State & Storage**: AsyncStorage & React hooks
- **Vector Graphics**: react-native-svg
- **Platform**: Android & iOS
